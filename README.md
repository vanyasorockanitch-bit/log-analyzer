# Log Analyzer

Учебный дипломный проект: веб-приложение на FastAPI для загрузки, парсинга и анализа лог-файлов с сохранением результатов и экспортом отчётов в PDF.

Проект показывает полный сценарий `upload → parse → normalize → analyze → explain → report → export`.

## Возможности

- веб-интерфейс и REST API на FastAPI;
- определение формата и парсинг Apache error / Nginx access логов;
- нормализация событий и сохранение в БД через SQLAlchemy;
- статистика и базовое выявление аномалий;
- локальное NLP/AI-assisted объяснение уникальных сообщений;
- сохранение отчётов по `report_id` и экспорт PDF;
- отдельная временная SQLite-БД для тестов.

## Стек

Python, FastAPI, Uvicorn, SQLAlchemy, SQLite (с возможностью `DATABASE_URL` для PostgreSQL), Pydantic, Transformers/PyTorch/SentencePiece, fpdf2, WeasyPrint, unittest, HTML/CSS/JavaScript.

## Запуск в Windows

1. Установите Python 3.12+.
2. Создайте окружение и установите зависимости:

```bat
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

3. Запустите приложение:

```bat
.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 7000
```

Откройте <http://127.0.0.1:7000>. Проверка API: `GET /api/health`.

`DATABASE_URL` необязателен: без него используется локальная SQLite-база. Пример настроек находится в `.env.example`.

## Тесты

```bat
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты используют изолированную временную SQLite-БД и не требуют PostgreSQL.

## Структура и материалы

- `app/` — FastAPI-приложение, роутеры, парсеры и сервисы;
- `tests/` — проверки парсеров и API-сценария;
- `logs/samples/` — небольшие примеры Apache/Nginx и неподдерживаемого формата;
- `docs/` — описание архитектуры, полей данных и демонстрации.

## Ограничения текущей учебной версии

Нет авторизации пользователей; основной проверенный сценарий рассчитан на небольшие файлы; CI/CD, Docker и production-развёртывание не настроены. NLP-модель может потребовать отдельной загрузки и настройки.

## AI-assisted development

При разработке использовались AI-инструменты для прототипирования, анализа решений, отладки и документации. Результат проверялся ручными сценариями и тестами проекта; уровень владения технологиями — учебный/базовый.
