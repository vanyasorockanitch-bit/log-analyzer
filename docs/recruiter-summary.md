# Project summary для резюме

Этот документ помогает быстро объяснить проект работодателю.

## Одно предложение

Log Analyzer — веб-приложение на FastAPI для загрузки, парсинга, хранения и анализа лог-файлов
с формированием человекопонятного аналитического отчёта и PDF-экспортом.

## Что показывает проект

- понимание backend-архитектуры;
- работу с API;
- работу с базой данных;
- обработку и нормализацию данных;
- проектирование полного пользовательского сценария;
- подготовку проекта к демонстрации;
- использование AI-assisted development как инструмента разработки.

## Стек

- Python
- FastAPI
- Uvicorn
- SQLAlchemy
- SQLite
- PostgreSQL-ready подход
- Transformers / PyTorch
- unittest
- HTML/CSS/JavaScript

## Как описывать в резюме

Вариант для блока «Проекты»:

> Разработал прототип веб-приложения Log Analyzer для загрузки, хранения и анализа лог-файлов.
> Система определяет формат файла, парсит события, нормализует данные, рассчитывает статистику
> и аномалии, сохраняет отчёты в базе данных и формирует PDF по сохранённому report_id.
> Стек: Python, FastAPI, SQLite, SQLAlchemy, NLP-модель, unittest.

## Как честно говорить про AI-assisted development

Корректная формулировка:

> Использовал AI-assisted development для прототипирования, анализа решений, отладки,
> документирования и ускорения разработки. Отвечал за постановку задач, проверку результата,
> интеграцию модулей и подготовку проекта к демонстрации.

Неудачная формулировка:

> Код писал ИИ, я сам почти не разбираюсь.

Почему неудачная: она обесценивает проект и создаёт впечатление, что кандидат не контролировал результат.
Лучше честно говорить о своём уровне, но показывать, за какие части процесса ты отвечал.
