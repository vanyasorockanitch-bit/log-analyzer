# Демонстрационные материалы

Эта папка предназначена для материалов, которые удобно показать работодателю или комиссии:
скриншоты, пример отчёта, тестовые логи и короткий сценарий демонстрации.

## Минимальный сценарий демонстрации

1. Запустить проект через `run_dev.bat`.
2. Открыть `http://127.0.0.1:7000`.
3. Загрузить пример Nginx или Apache log.
4. Показать, что система определила формат и распарсила события.
5. Открыть статистику и аномалии.
6. Запустить NLP-объяснение уникальных сообщений.
7. Сформировать отчёт.
8. Скачать PDF по сохранённому `report_id`.

## Что важно показать работодателю

- проект не является одним скриптом, а оформлен как backend-приложение;
- есть API, база данных, обработка данных и отчётность;
- логика разделена по модулям;
- отчёт сохраняется и может быть повторно открыт;
- PDF строится по сохранённым данным;
- архитектура подготовлена к расширению.

## Рекомендация перед откликами

Перед отправкой ссылки на GitHub проверь репозиторий в режиме инкогнито.
Если ссылка открывается с ошибкой 404, значит репозиторий приватный или доступ ограничен.
Для резюме репозиторий должен быть публичным или работодатель должен получить доступ.
